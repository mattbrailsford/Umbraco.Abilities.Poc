# Umbraco.Abilities.AI

Abilities as tools for a chat with a model, such as Umbraco.AI's.

| File | What it is |
| --- | --- |
| `AiChatConsumer.cs` | Who the AI chat is, as a consumer: a model reads it, it keeps a conversation, and it can ask the person |
| `AbilityAITools.cs` | The consumer's tools as M.E.AI functions. Ones that can't be undone ask the person first |
| `AbilityAIFunction.cs` | One tool as one M.E.AI function |
